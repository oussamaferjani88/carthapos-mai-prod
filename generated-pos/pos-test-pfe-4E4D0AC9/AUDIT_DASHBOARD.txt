7. ISSUES & GAPS
================================================================================

  BUGS:
  -----
  [1] Misleading KPI labels: "Ventes du jour" / "Revenus du jour" display
      ALL-TIME data, not today's data. No WHERE clause filters by date.

  [2] N+1 query: 5 separate queries fired to count items per order.
      Should be a single JOIN or subquery.

  [3] Icon color override: Inline style backgroundColor from config.primaryColor
      overrides all 4 distinct Tailwind color classes on icon badges.

  [4] Chart month collision: Multi-year data shows duplicate month labels
      with no year distinction (e.g. "Jan" appears twice).

  [5] "View Reports" button is non-functional (no onClick, no navigation).

  SECURITY:
  ---------
  [6] Raw SQL passthrough: The generic 'database:query' channel accepts ANY
      SQL with no validation. Dashboard constructs safe static SQL, but the
      channel itself is an attack surface.

  PERFORMANCE:
  ------------
  [7] No query optimizer: Dashboard bypasses DatabaseQueryOptimizer.cjs
      which provides caching and timeout protection.

  [8] No memoization: statsArray, config, styles, formatCurrency are all
      recomputed on every render. No useMemo/useCallback usage.

  MISSING FEATURES:
  -----------------
  [9] No "today's data" filter despite card labels suggesting it.

  [10] No trend/comparison data in production mode (only in preview).

  [11] No real-time clock or date display in header.

  [12] No manual refresh button.

  [13] Hardcoded alert threshold: "Objectif atteint" triggers at totalSales > 20.
       Should be configurable.

  [14] No dedicated dashboard backend handler. All logic is inline in the
       React component. No server-side aggregation or caching.

  [15] Empty dashboard.css file (0 bytes).

  [16] No user-visible error state on query failure.

  CODE QUALITY:
  -------------
  [17] Excessive console.log statements (~20+ debug logs in production code).

  [18] Unused imports: Users, DollarSign, Clock from lucide-react.

  [19] Dashboard defines its own Card/CardHeader/CardTitle/CardContent
       components instead of importing from ui/card.

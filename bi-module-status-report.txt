8. WHAT WORKS RIGHT NOW
   - Admin can upload ZIP files via /bi-upload-portal
   - ETL pipeline processes uploads (extract, validate, load dims, load facts)
   - BI requests can be created, approved, paid
   - BI analysis: pending → under analysis → completed with insights
   - Dashboard creation: POST /api/bi/dashboards/generate-from-upload creates
     a BiDashboard record (DRAFT status) linked to a Metabase template if one exists
   - AdminDashboardViewer shows dashboard info + "Open in Metabase" button
   - Dashboard lifecycle: DRAFT → IN_PROGRESS → READY_FOR_REVIEW → PUBLISHED
   - Notifications on PUBLISH
   - Client portal lists published dashboards and shows Metabase link

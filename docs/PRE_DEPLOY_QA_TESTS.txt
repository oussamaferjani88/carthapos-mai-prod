================================================================================
CARTHAPOS - PRE-DEPLOYMENT Q&A TEST SUITE
================================================================================
Purpose : test EVERYTHING (admin panel, client interface, generated POS apps
          for RETAIL and RESTAURANT) to find real problems BEFORE deploying.

How to use
----------
- Run each test. Enter PASS / FAIL / N/A in the Result box.
- Record any error messages / console errors verbatim next to failures.
- "Expected" states the correct behaviour. Anything else = defect.
- The generated POS must be REGENERATED first (pos-template blueprint changed):
  generate 4 POS: Retail (no tables/kitchen), Restaurant (without tables/kitchen),
  Restaurant (with tables+kitchen) ~ a 4th can be the retail/kitchen combo if needed.
- A USB stick with a valid license file is required for USB-based license tests.
- Backend, admin, frontend must be running from FRESH builds (npm/pnpm build).

Personas
--------
- ADMIN  : SUPER_ADMIN account (backend/.env ADMIN_INITIAL_* credentials)
- MANAGER: admin staff with limited permissions (test RBAC)
- CLIENT : client account created from the client portal (frontend register)

Module keys referenced (backend/prisma/seed.js):
  tables="Gestion des tables", kitchen="Cuisine", menu-management, takeaway,
  inventory, suppliers, variants, promotions, serial-batch, weight-scale,
  customer-management, loyalty, gift-cards, layaway, barcode, reports.
HIDDEN in admin module grid (not selectable, defined in ModuleGrid.jsx):
  split-payments, offline-mode, tax-management.

Legend: [Q] = test question / action   [EXPECTED] = correct outcome
================================================================================

======================================================================
  NOTES TECHNIQUES
======================================================================

  • Tous les composants Admin/Frontend utilisent des données démo
    statiques car ces environnements de prévisualisation n'ont pas
    accès à la base SQLite.
  • L'Électron POS utilise les appels IPC réels via window.electronAPI
    avec fallback vers les données démo si l'API n'est pas disponible
    (mode dev web).
  • Les handlers IPC suivent le pattern existant :
    registerXxxHandlers(ipcMainInstance, databaseManager).
  • Les nouveaux composants Preview utilisent le pattern config-driven
    existant (props config, setNotification) avec les mêmes classes
    Tailwind et icônes lucide-react.
  • Le positionnement des tables par drag & drop utilise les événements
    souris (pas de librairie externe) pour correspondre au style du
    calculateur dans Sales.jsx.

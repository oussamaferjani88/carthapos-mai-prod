1. RACINE DU PROBLÈME « RECTANGLE BLANC AU SCROLL »
--------------------------------------------------------------------------------
Cause : ancien Layout = div.h-screen + main qui faisait du overflow-y-auto
sans que ses enfants flex ne soient contraints (min-h-0 / min-w-0 absents)
et AppShell enveloppait tout dans min-h-screen. Les pages plus hautes que
l'écran produisaient un espace vide résiduel en bas.

Correction structurelle (pas cosmétique) :
- App.jsx : AppShell passe de `min-h-screen` à `h-full` (html/body/#root
  font maintenant height:100% via App.css).
- Layout.jsx : cadre = div.h-screen.overflow-hidden > header flex-shrink-0
  + div.flex.min-h-0.flex-1 > aside + main.min-w-0.flex-1.overflow-y-auto.
  Le scroll vit uniquement dans <main>, les enfants flex sont contraints.

### Why This Order Is Better

1. **Sector first** -- grounds user, pre-fills everything.
2. **Brand before theme** -- business name/logo are most personal, come first.
3. **Theme before details** -- user sees complete POS quickly, then refines.
4. **Progressive disclosure** -- each step reveals only what's relevant.
5. **Linear progression** -- steps 1-8. No 2.5 or 2.7.
6. **Receipt near end** -- depends on brand info from Step 2.
7. **Preview always visible** -- real-time updates as user adjusts.

### UX Rules

- Preview panel on the right every step
- Changes appear instantly (no Apply button)
- Persistent header: Step name, Return to Step X, Save Draft
- User can click any step in progress bar to jump back
- Generate only on Step 8
- All settings auto-save debounced 500ms

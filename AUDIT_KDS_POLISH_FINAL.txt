4. DETAILED IMPROVEMENTS
═══════════════════════════════════════════════════════════════════

── 4.1 PROFESSIONAL UX ──────────────────────────────────────────

  • Better spacing: Consistent px-6/px-4 gaps, py-2/py-3 padding
  • Typography hierarchy: text-lg font-bold headers, text-xs labels,
    text-sm content, text-[11px] micro-details
  • Card shadows: shadow-sm → hover:shadow-lg transition
  • Transitions: duration-200 on all interactive elements
  • Hover animations: scale, shadow, bg changes on cards
  • Loading states: SkeletonKitchen with animated pulse
  • Empty states: Centered icons with descriptive text
  • Responsive: grid-cols-1/2/3/4 responsive breakpoints

── 4.2 ORDER CARD ───────────────────────────────────────────────

  • Bigger table number: font-extrabold text-base in muted badge
  • Server name: Users icon + name
  • Customer: Bold text-foreground name
  • Preparation timer: 1-second update, tabular-nums, color-coded
  • Estimated completion: "⏱ ~Xmin" display
  • Delay indicator: "Retard" badge + pulsing red ring
  • Quick actions: Start/Ready/Served/Cancel directly on card
  • Selection checkbox: CheckSquare/Square toggle
  • Draggable: HTML5 drag API with cursor-grab styling
  • Department badge: Icon + name in compact pill

── 4.3 TIMERS ───────────────────────────────────────────────────

  • 1-second internal interval per OrderCard
  • formatElapsed enhanced:
    - <1 min: seconds display (e.g., "45s")
    - 1-5 min: "X:SS" format (e.g., "3:42")
    - 5-60 min: "X min" format
    - 60+ min: "XhYmin" format
  • Color transitions:
    - 0-5 min: text-emerald-600 (green)
    - 5-10 min: text-amber-500 (yellow)
    - 10-15 min: text-orange-500 (orange)
    - 15-20 min: text-red-500 (red)
    - 20+ min: text-red-600 animate-pulse (flashing)
  • Background highlight: bg-red-50 for overdue timers
  • Estimated remaining: "Xmin rest." or "+retard Xmin"

── 4.4 DRAG & DROP ─────────────────────────────────────────────

  • HTML5 Drag and Drop API (no library)
  • OrderCard: draggable attribute, onDragStart with JSON data
  • KanbanColumn: onDragOver, onDragLeave, onDrop handlers
  • Visual feedback: bg-primary/5 + ring-2 + "Déposez ici" text
  • Status transition: dropping triggers updateStatus(targetColKey)
  • Backend validation: invalid transitions rejected with toast

── 4.5 QUICK ACTIONS ────────────────────────────────────────────

  • Every card shows: [Start/Ready/Served] + [Cancel] + [Details] + [Print]
  • Start button: bg-amber-500 for pending cards
  • Ready button: bg-blue-600 for preparing cards
  • Served button: bg-green-600 for ready cards
  • Cancel: destructive outline with Ban icon
  • All buttons have min-h-8 (32px) touch targets
  • aria-label on every action button

── 4.6 BULK ACTIONS ────────────────────────────────────────────

  • Selection: Checkbox on each card (toggleSelect)
  • Selection count: "X sélectionnée(s)" in action bar
  • Batch actions: Start Selected, Ready Selected, Serve Selected,
    Cancel Selected, Print Selected
  • Auto-clear selection after batch operation
  • "Tout désélectionner" button
  • Global batch buttons: "Tout commencer", "Tout prêt", "Tout servi"
    (visible when no selection)

── 4.7 SEARCH ───────────────────────────────────────────────────

  • Simultaneous search across:
    - Order ID (sale_id)
    - Table number
    - Server name
    - Customer name
    - Notes
    - Department
    - Product names (within items array)
  • Case-insensitive matching
  • Instant filtering (useMemo)

── 4.8 FILTERS ──────────────────────────────────────────────────

  • Toggleable filter panel (SlidersHorizontal button)
  • Priority filter: All/Low/Normal/High/Urgent
  • Server name filter: Text input
  • Overdue only toggle: Switch component
  • Reset button: One-click filter reset
  • Filters combine with search and department tabs

── 4.9 HISTORY ──────────────────────────────────────────────────

  • Pagination: Prev/Next with page number
  • Server-side offset/limit (HISTORY_LIMIT = 20)
  • Date range: From/To date pickers
  • Department filter: Select dropdown
  • Priority filter: Select dropdown
  • Status filter: All/Completed/Cancelled/Served
  • Export CSV: UTF-8 BOM, quoted fields, proper escaping
  • Grid layout: 1/2/3/4 columns responsive

  • React.memo on: OrderCard, StatsBar, DepartmentTabs, KanbanColumn
  • useMemo on: filteredOrders, kanbanColumns, statsBar, pendingIds,

── 4.11 PRINTING ────────────────────────────────────────────────

  • Department icon on ticket header
  • Double-line separators (═══)
  • Bold section headers (ARTICLES:, NOTE:)

    - 🟡 En attente (order_received) — amber
    - 🔵 En cours (preparing) — blue
    - 🟢 Prêt (ready) — emerald
    - ✅ Servi (served) — green
    - ❌ Annulé (cancelled) — red
  • Sale detail modal: Kitchen status in info grid
  • Only shown when kitchen_status exists and is active
  • Color-coded text matching status

── 4.14 ANALYTICS PANELS ────────────────────────────────────────

  • New "Stats" tab in KDS view
  • 4 sub-tabs: Départements, Employés, Produits, SLA
  • Department cards:
    - Icon + name + busy level badge
    - Load bar (color-coded by busy_level)
    - Status counts (pending/preparing/ready)
    - Average wait time, prep time
    - Overdue count
  • Employee performance table:
    - Server name, total, completed, active, cancelled
    - Average prep time, completion rate %
  • Top products table:
    - Product name, times prepared, completed, cancelled
  • SLA summary cards:
    - Department, target time, compliance %
    - Progress bar with color coding
    - "X/Y commandes dans les temps"

  • Desktop notifications via Notification API

  • Toast notifications with descriptions
  • Sound toggle button in toolbar
